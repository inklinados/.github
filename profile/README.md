# Inklinados

Somos um coletivo de desenvolvedores cristãos. Cada um tem o próprio projeto e os outros ajudam no que podem.

Ninguém é chefe de ninguém, ninguém trabalha sozinho. Entra-se por projeto: mostra o próprio trabalho primeiro, ajuda quando o projeto de outro precisa.

A casa fica no repositório [comunidade](https://github.com/inklinados/comunidade), onde moram o charter, o acordo de trabalho e as regras de infraestrutura. Não somos empresa; dinheiro, quando houver, é por contrato e fora do coletivo. Regras existem só para o espaço continuar leve.
